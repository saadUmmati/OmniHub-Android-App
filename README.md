# 🌌 OmniHub - Multi-Utility Android App

OmniHub is a sleek, professional Android application designed with a **Spectral Intelligence** aesthetic. It integrates real-time weather tracking, global news updates, and contact management into a seamless, high-performance experience.



## ✨ Features

- **🌤️ Dynamic Weather:** Real-time, location-based weather updates using OpenWeather API. Features dynamic icons that change based on weather conditions (Sun, Clouds, Rain, etc.).
- **📰 Tech News:** Stay updated with the latest headlines integrated via NewsAPI, organized in a clean, readable card layout.
- **📇 Contact Manager:** A professional contacts list fetched directly from the device with smooth scrolling behaviors.
- **🌀 Immersive UI:** Edge-to-edge display with custom navigation, sleek fade animations, and a premium Obsidian Black & Electric Violet theme.
- **🔄 Smart Refresh:** Integrated `SwipeRefreshLayout` for manual data updates and ViewPager2 for fluid fragment transitions.

## 🛠️ Tech Stack

- **Language:** Kotlin
- **Architecture:** MVVM (Model-View-ViewModel)
- **Networking:** Retrofit & GSON
- **UI Components:** ViewPager2, Material 3, CoordinatorLayout, ConstraintLayout
- **Concurrency:** Kotlin Coroutines
- **Lifecycle:** LiveData, ViewModel, Lifecycle-aware components
